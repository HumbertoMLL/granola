3 ADR · decisiones tomadas

0001 · aceptado

Neon + Better Auth, no Supabase

RLS desde cliente causó 16K bases expuestas; 152 incidentes en 2026; HIPAA desde $599. Postgres puro = salida con pg_dump. Autorización en la API, nunca en el cliente.

0002 · aceptado

WhatsApp Cloud API directo, número de Granola

Sin Twilio. MVP: un número envía plantillas en nombre de la nutri. F2: cada nutri conecta el suyo (Embedded Signup).

0003 · aceptado

Design system propio, cálido y claro

Crema #FBF7F0 · café #2B2118 · verde #4A7A2B · miel #E8A93B. Plus Jakarta Sans + Instrument Serif. Mobile-first. Nada del dark de IA Sin Bullshit.

0004 · implementado

Stripe destination charges + MP pago directo

Un solo webhook, 0% application fee, la nutri es merchant of record. MP con /v1/payments para tener la CLABE en nuestra página. Split de MP al nutri = F1.5.

0005 · implementado

Scheduling puro, sin librería de fechas

Intl.DateTimeFormat maneja DST; corre igual en Node y navegador. Paso 30 min, aviso 2h, horizonte 28 días. 40 tests.

0006 · implementado

Inngest para recordatorios

sleepUntil + cancelOn por cita: si reagendan, el run viejo muere solo. Portable, self-host posible.
